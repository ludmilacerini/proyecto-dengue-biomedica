# 🦟 Sistema de Monitoreo y Predicción de Dengue — Argentina

## 📋 Descripción del Proyecto
Este proyecto integrador de **Ingeniería Biomédica** consiste en el desarrollo de una herramienta informática y epidemiológica para el monitoreo, visualización y predicción de la incidencia de dengue en Argentina. Integra datos epidemiológicos, variables climáticas y factores sociodemográficos.

## 🛠️ Estructura del Repositorio
* `app.py`: Aplicación web interactiva desarrollada en Python con Streamlit.
* `requirements.txt`: Librerías de Python requeridas para el entorno de producción.
* `README.md`: Documentación y presentación del repositorio.

## 🚀 Tecnologías Utilizadas
* **Lenguaje:** Python 3.x
* **Dashboard Web:** Streamlit
* **Gráficos y Mapas:** Plotly (go.Scattergeo / px.line)
